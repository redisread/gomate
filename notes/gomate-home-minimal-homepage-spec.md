## 0. 一句话

**内容即界面，装饰归零。** 首屏从「口号 + 营销腔」变为「口号 + 搜索 + 三张真实地点卡」——吸引力来自内容本身。风格 token 零改动，只动布局与取舍。

## 1. 诊断（为什么现在不吸引人）

匿名访客首屏实测（桌面 900px / 移动 844px 视口）：

1. **首屏零内容**：hero 区 ~600px 被 pill 徽章 + H1 + 副标 + 搜索 + 双 CTA + 3 个自夸 badges 占满，真实地点内容全在第二屏
2. **CTA 通胀**：一页三个「创建队伍」（hero 双 CTA、空态 CTA、底部 banner CTA）互相稀释，且与顶部导航「探索地点/找队伍」完全重复
3. **反卖点空态**：「近期队伍」整区向匿名访客展示「暂无活跃队伍」——首页在喊这里没人
4. **营销腔噪音**：「三步开启户外之旅」解释显而易见的事；各区块 eyebrow 小标签（本周去这三个/精选地点/使用流程…）制造假层级

## 2. 设计原则（raft 哲学翻译）

- **内容即界面**：首屏必须出现真实内容（地点卡），不只是口号
- **装饰归零**：不为「看起来丰富」保留任何无信息元素
- **单一焦点**：每个视图只有一个主动作；琥珀色只给真实行动点
- **风格不动**：琥珀/cream 底色/卡片样式/hover/圆角/i18n 全部保留，本 spec 不含任何 token 变更

## 4. 新布局

### 4.1 桌面（1440，视口 900px）

```
Navbar（不在范围）
├─ Hero（~280px，压缩自 ~600px）
│   H1 发现趣处 组队同行
│   副标 找到同行的人，出发就不远。
│   [🔍 搜索地点、活动或队伍…]      ← 唯一动作
├─ 本周三个选择                     ← 首屏线（900px）穿过本区
│   标题 + 换一批 →（文字按钮）
│   [卡][卡][卡]
├─ 本地圈子（登录态，不动）
├─ 探索地点
│   标题 + 6 卡 grid（3×2）
├─ 近期队伍（条件渲染，§5）
└─ Footer（不在范围）
```

**首屏 = 口号 + 搜索 + 本周三卡（部分或全部）**。这是「一开始就吸引人」的 mechanism：第一眼看到的是真实地点，不是自我介绍。

### 4.2 移动（390，视口 844px）

- Hero 同构压缩（H1 两行 + 副标 + 搜索框）
- 本周三个选择：**横滑 snap**，一次一张半（溢出半张 = 滑动 cue），不堆三行长卡
- 探索地点：**紧凑卡**（左图右文，高约 95px 等比），替代当前全宽图顶大卡，6 卡高度省 ~50%
- 近期队伍：同条件渲染

## 5. 条件渲染规则（近期队伍）

- `teams.length > 0` → 正常渲染（标题 + 队伍卡）
- `teams.length === 0` → **整区不渲染**（无占位、无空态文案、无「查看全部」），无论匿名/登录
- 登录用户的创建入口不丢失：顶部导航「找队伍」页内有创建入口（现状如此，不在本 spec 改动）
- 本地圈子/引导卡现有显隐逻辑不变（P0-D/#185 spec 已定义）

## 6. 视觉规范

### 6.1 Hero 压缩

- 桌面 hero 区高度 ~600px → **~280px**（H1 + 副标 + 搜索框 + 上下 padding）
- 移动端同构（H1 两行，总高 ~250px）
- 删除元素见 §3 砍 1/2/3；保留搜索框现有样式与 bounce 动效

### 6.2 区块顺序与间距

- 顺序固定：Hero → 本周三个选择 → 本地圈子（登录态）→ 探索地点 → 近期队伍（条件）
- 区块间距统一（建议沿用现有 section padding 上限值，全页一种节奏）

### 6.3 标题层级单层化

- 现状三层：eyebrow 小标签 + H2 + 副标 → **单层：区块标题**
- 字号对比拉开：H1 56（现状）/ 区块标题 ~28 / 正文 16；区块标题字重 600-700
- 「换一批」从按钮形态弱化为文字链接样式（琥珀色，右对齐于标题行）

### 6.4 移动端卡片

- 本周三卡：横滑容器 `scroll-snap-type: x mandatory`，卡宽 ~68% 视口（露出次卡 ~半张）
- 探索地点紧凑卡：左缩略图（方形 ~80px）+ 右侧名称/参数两行，整卡高 ~95px，纵向堆叠

## 7. i18n

- 删除元素对应 keys 清理（hero badge / how-it-works / cta banner / 空态 noTeams 等），三语同步
- 「换一批」等保留元素文案不动
- i18n 门禁（validate-i18n-keys，含 ja）必须过

## 8. 验收标准

1. 桌面 1440×900 首屏内可见：H1 + 副标 + 搜索框 + 本周三个选择标题与至少 2 张卡
2. 移动 390×844 首屏内可见：H1 + 搜索框 + 本周三个选择首张卡
3. 页面无：pill 徽章 / hero 双 CTA / 3 badges / 三步区 / 底部 CTA banner / eyebrow 标签（DOM 零节点）
4. 无活跃队伍时「近期队伍」整区零节点；有队伍时正常渲染
5. 登录态：本地圈子 + 引导卡 + OnboardingModal 行为与现状一致（不回归）
6. 移动端本周三卡可横滑且 snap 定位；探索地点紧凑卡左图右文
7. 风格抽查：琥珀/cream/卡片 hover 与现状一致（token 零改动）
8. i18n 门禁三语通过；暗色模式不破版
9. 首屏 LCP 不劣化（hero 图片预加载逻辑 PreloadImages 保留）
