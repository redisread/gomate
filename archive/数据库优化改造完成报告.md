# 数据库结构优化改造完成报告

## 改造概述

本次改造优化了 GoMate 项目的数据库结构，主要涉及 `cities`、`routes` 和新增的 `waypoints` 表，提升了查询性能和数据管理能力。

---

## 改造内容

### 1. Cities 表优化

#### 新增字段
- `updated_at`: 更新时间字段（INTEGER, timestamp）

#### 影响
- 现在可以追踪城市信息的修改历史
- 与其他表的时间戳字段保持一致

---

### 2. Routes 表字段类型改造

#### 删除的字段（旧结构）
- `duration: TEXT` - 如 "4-5小时"
- `distance: TEXT` - 如 "8.5公里"
- `elevation: TEXT` - 如 "869米"
- `waypoints: TEXT` - JSON 数组
- `equipmentNeeded: TEXT` - JSON 数组
- `warnings: TEXT` - JSON 数组

#### 新增的字段（新结构）
- `duration_min: INTEGER` - 最短耗时（分钟）
- `duration_max: INTEGER` - 最长耗时（分钟）
- `distance: REAL` - 路线长度（公里）
- `elevation: INTEGER` - 累计爬升（米）
- `extra: TEXT` - 扩展字段 JSON: `{ equipmentNeeded: string[], warnings: string[] }`

#### 新增索引
- `routes_duration_idx` - 复合索引 (duration_min, duration_max)
- `routes_distance_idx` - 单列索引 (distance)
- `routes_elevation_idx` - 单列索引 (elevation)

#### 优势
1. **支持范围查询**：可以按距离、时长、海拔进行范围筛选
2. **支持排序**：可以按数值字段排序（如按海拔从高到低）
3. **性能提升**：数值索引查询比字符串解析快
4. **数据完整性**：类型约束确保数据有效性

---

### 3. Waypoints 表拆分

#### 新建表结构
```sql
CREATE TABLE waypoints (
  id TEXT PRIMARY KEY NOT NULL,
  route_id TEXT NOT NULL REFERENCES routes(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  description TEXT,
  coordinates TEXT NOT NULL,  -- JSON: { lat: number; lng: number }
  "order" INTEGER NOT NULL,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);
```

#### 索引
- `waypoints_route_idx` - 单列索引 (route_id)
- `waypoints_order_idx` - 复合索引 (route_id, order)
- `waypoints_route_order_idx` - 唯一索引 (route_id, order)

#### 优势
1. **独立管理**：途径点可以独立增删改查
2. **数据完整性**：外键约束确保数据一致性
3. **顺序保证**：唯一索引确保同一路线的 order 不重复
4. **扩展性强**：未来可以为途径点添加更多属性（如图片、海拔等）

## 查询能力增强

### 新支持的查询场景

#### 1. 按距离范围筛选
```sql
SELECT * FROM routes WHERE distance BETWEEN 5 AND 10;
```

#### 2. 按时长范围筛选
```sql
SELECT * FROM routes WHERE duration_min <= 180 AND duration_max <= 300;
```

#### 3. 按海拔排序
```sql
SELECT * FROM routes WHERE elevation >= 500 ORDER BY elevation DESC;
```

#### 4. 组合条件查询
```sql
SELECT * FROM routes
WHERE distance <= 10
  AND duration_max <= 360
  AND elevation >= 500
ORDER BY distance ASC;
```
