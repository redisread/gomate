# 页脚旅行明信片改造

## 已确认意图
上方品牌与导航，下方山野、湖泊、步道和结伴人物；暖纸色与深蓝。兼顾桌面与手机，范围仅页脚。用户已确认方向并授权执行。

## 实现决策
- 原创静态插画作为装饰，文字与链接保持 HTML；图片懒加载、固定尺寸、压缩 WebP。
- 一套响应式 DOM 代替 hydration 后切换移动版；手机直接展示紧凑链接，桌面品牌加三组导航。
- 保留所有现有链接、邮箱、社交入口和二维码功能，复用 Modal 的键盘焦点管理。
- 不改 API、数据库、部署配置和其他页面布局。深色主题独立语义 token，不增加视差或循环动画。

## 顺序
1. 原创插画与媒体预算。
2. 页脚布局、交互及行为回归。
3. 多尺寸双语/主题浏览器验证、全门禁、独立审查、PR/受保护合并、生产只读 smoke。

## 风险
- 插画体积：WebP + srcset，明确预算；缺图不影响链接。
- 小屏/英文溢出：320/390/768/1440 实测；触控目标至少 44px。
- SSR 位移：CSS 断点与预留媒体高度；不再依赖 window.innerWidth 分支。
- 生产：只经已审核 PR 合并发布；恢复走受保护 revert PR，无数据迁移。
