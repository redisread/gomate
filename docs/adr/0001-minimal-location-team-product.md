# 将产品收敛为地点发现与线下组队

2026-10-17，用户确认 GoMate 的核心流程为“发现地点 → 找到或创建队伍 → 完成线下活动”。用户说明目前只有测试用户，因此选择允许破坏性改造，优先减少产品功能和维护成本，而不是为非核心能力继续维护兼容层。本记录表示范围决策已接受，不表示改造已完成或生产数据已清理。

## 保留与简化

保留中英文、地点浏览/筛选/详情、注册登录、最小个人资料，以及队伍创建、直接加入、退出、人数上限、必要成员管理、活动时间地点、取消与完成；保留支撑这些能力的最小管理员后台。加入队伍统一为有名额即可直接加入，删除申请理由、审批列表和审批通知；人数与权限约束仍须在最终写入处保证。必要集合信息并入队伍，联系与反馈合并为一个轻量入口。

## 明确删除

删除故事及关联点赞、收藏和媒体管理，站内聊天/会话/未读体系，个性化与新手推荐，首页邻居/活跃度聚合，行动本中的装备分配/认领/交通协作，地点收藏和分享海报。删除覆盖相关页面、API、数据库结构、后台任务、依赖、测试及文档；共享能力须确认其保留功能的消费者，不因删除一个模块误删仍需的能力。

删除 ja 翻译、选项、路由支持、邮件/海报模板和语言专用逻辑，不新增日语旧链接重定向、Cookie 专用迁移或 API 参数转换。仅保留中文和英文；用户编写的日语文本不因其语言被清洗。

## 后果与边界

允许修改数据库结构和移除已删除功能的测试数据，不为旧 API、页面或测试账号保留业务兼容分支。这不是直接清空生产 D1/R2 的授权：远程变更仍须明确目标与范围，遵循受保护发布、migration 和生产变更规约；代码回滚不能恢复已删除的数据。

仓库 docs/ 为面向开发者与代码代理的权威参考；Notion 保存讨论、决策关联和任务进度。文档区分当前代码事实、必须遵守的约束与未实施建议，依据实际 Cloudflare 配置及对应官方文档复核，不把平台可用能力写成项目已实现能力。自动 OpenAPI 负责接口字段与操作目录，手写说明聚焦业务语义和运行边界。
