#### 1.1 访客 → 登录流程
**角色 3（访客）执行：**

**验证点：**
- 路由守卫正确拦截未登录用户
- 登录页 UI 正常（邮箱 + 密码表单）
- 密码可见性切换（Eye/EyeOff 图标）

#### 1.2 登录流程（角色 3 → 角色 1）
**角色 3（访客）执行：**
1. 输入邮箱：`wujiahong2013@gmail.com`

3. 点击「登录」按钮

**验证点：**
- Loading 状态显示
