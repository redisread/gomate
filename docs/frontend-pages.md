# GoMate 前端页面功能文档

> 最后更新：2026-07-03
> 架构：Astro 7 SSR 壳 + React Islands（核心浏览页使用 `client:only="react"`）

## 概览

前端共 **25 个页面**，按功能分为 9 个模块：

| 模块 | 页面数 | 是否需登录 |
|------|--------|-----------|
| 认证 | 4 | 否 |
| 地点 | 2 | 否 |
| 队伍 | 5 | 部分 |
| 用户 | 4 | 部分 |
| 首页 | 1 | 否 |
| 信息页 | 5 | 否 |
| 管理 | 1 | 是（Admin） |
| 用户功能 | 2 | 是 |
| 博客 | 2 | 否 |

全站 UI 当前采用像素风展示层：`Layout.astro` 提供像素色板、字体预加载和全局导航/页脚壳，`styles/globals.css` 统一覆盖卡片、按钮、输入框、徽章、图片边框、阴影和旧渐变装饰。首页、地点列表和队伍列表是高交互 React 页面，使用 `client:only="react"` 避免服务端首帧数据或 i18n 缓存与客户端状态不一致导致 hydration mismatch。

## 页面详情

### 1. 首页 `/`

**组件：** `components/features/home-client.tsx`
**认证要求：** 否

**功能点：**
- Hero 区：像素字体大标题 + 网格背景 + 硬边阴影
- 搜索栏：关键词输入 + 清空按钮
- CTA 按钮组：「探索地点」「找队伍」
- 数字统计徽章：50+ 路线、200+ 玩家、1000+ 安全
- 精选地点卡片网格（3 列，含分页）
- 使用流程说明（3 步引导）
- 近期队伍卡片列表（双列，含倒计时提示）
- 旧浮动模糊装饰已由像素边框和硬阴影替代

**关键交互：**
- 页面作为 React island 仅客户端渲染，保留现有数据流和交互逻辑
- 搜索跳转到地点列表页
- 页面滚动入场动画（Intersection Observer）
- 数字计数动画（CountUp）
- 视差滚动效果

### 2. 地点列表页 `/locations`

**组件：** `components/features/locations-client.tsx`
**认证要求：** 否

**功能点：**
- Hero 搜索区（像素网格背景 + 硬边卡片）
  - 搜索框（玻璃效果 + 清空按钮）
  - 城市下拉筛选（单选，外部点击关闭）
  - 热门标签多选（点击切换激活态）
  - 已选条件 Badge（可逐个删除 / 全清）
- 地点卡片网格（3 列响应式，像素边框和硬阴影）
  - 卡片信息：封面图、难度徽章、最佳季节、名称、地址、描述、标签
  - Hover：图片放大 + 卡片上升 + 阴影增强
- 骨架屏（shimmer 扫光，加载时显示 6 张）
- 空状态（浮动图标 + 情感化文案 + CTA 按钮）
- 分页器（页码 + 省略号处理）

**关键交互：**
- 页面作为 React island 仅客户端渲染，避免 SSR API 空数据与客户端状态产生水合差异
- 搜索防抖 300ms
- 城市 + 标签组合筛选
- URL 参数持久化（`q`、`tags`、`page`、`cityId`）
- 分页切换时 fade 过渡 + 卡片重新入场动画

### 3. 地点详情页 `/locations/[id]`

**组件：** `components/features/location-detail-client.tsx`、`location-detail-main-content.tsx`

**功能点：**

  - 右上角编辑 / 分享 / 收藏图标操作

  - 难度徽章 + 最佳季节 + 标题 + 路线快速指标

  - 支持多路线切换

- 侧边栏 sticky 操作卡（「创建队伍」+ 「浏览队伍」）

**关键交互：**
- 分享（Web Share API 优先，不支持则触发 SharePosterModal 生成海报）
- 收藏（前端状态切换，heartbeat 动效）
- Hero 图片 Lightbox（封面图 / 多图切换 / 全屏查看）
- 图片 Lightbox（点击打卡点图片全屏预览）
- 移动端底部浮动 CTA（离开 Hero 后展示；极窄屏按钮等宽避免文案挤压）

- **地点封面图（大尺寸，可点击）**：
  - 封面图区（h-[300px] lg:h-[400px]，渐变遮罩）
  - 城市标签（右上角药丸）
  - 路线信息（时长 + 距离，可选）
  - "查看地点详情"按钮（底部药丸，hover 效果）
  - 点击整个卡片跳转地点详情页

    - `canJoin`：进度条 + 留言 textarea + 申请按钮
    - `isPending`：待审批提示
    - `isMember`：已加入徽章 + 退出按钮
    - `isLeader`：已加入徽章 + 「编辑队伍」链接 + 「组建队伍」按钮（recruiting/full 状态可见）
    - `isClosed`：关闭提示
    - `approvedMember`：审批操作卡（待审批申请列表 + 批准/拒绝按钮）
  - 安全提示卡（4 条）
- 移动端底部固定栏（44px，safe-area-inset-bottom）
- 移动端 Bottom Sheet（加入队伍面板）
- 退出确认对话框（AlertDialog）
- 组建队伍确认对话框（满员/不满员两种提示）
- Toast 消息提示（替代 alert()）
- 分享海报弹窗（Canvas 生成 + QR Code，支持保存图片）

**关键交互：**
- 加入队伍（提交申请 + 留言）
- 退出队伍（二次确认）
- 组建队伍（队长操作，将队伍状态从 recruiting/full 改为 formed）
- 编辑队伍（跳转编辑页）
- 审批申请（批准/拒绝待审批成员）
- 成员列表折叠/展开
- **点击地点卡片跳转地点详情页**（整个卡片可点击）
- 分享（触发 SharePosterModal，Canvas 绘制海报 + 二维码）
- Toast 成功/错误反馈

### 6. 创建队伍页 `/teams/create`

**组件：** `components/features/create-team-client.tsx`
**认证要求：** 是（自动跳转登录）

**功能点：**
- 多步骤表单流程：
  - **步骤 1：选择地点**（地点下拉搜索，支持关键词筛选）
  - **步骤 2：选择路线**（该地点关联的路线列表）
  - **步骤 3：填写详情**（时间、人数、描述）
- 表单字段：
  - 队伍标题（必填，≥3 字）
  - 地点选择（下拉，必填）
  - 路线选择（可选，关联地点后显示）
  - 出发日期（默认今天 + 3 天）
  - 出发时间（默认 4 小时后）
  - 时长（分钟，根据路线智能推荐）
  - 最大人数（必填，默认 10）
  - 队伍描述（可选）
  - 参与要求（动态列表，可添加/删除）
- URL 参数预填（`locationId`）
- 表单验证 + 提交后跳转队伍详情页
- 时长智能推荐（根据路线数据自动计算）

## 设计系统摘要

### 颜色体系
- **主色（品牌绿）**：Emerald `#249a87` / `#1a6459`
- **强调色（暖橙）**：Amber / Orange `#ff7a65` / `#fbbf24`
- **中性色**：Stone `#1e1812` / `#8f7f6e` / `#e8e7e4`

### 动效规范
| 类型 | 实现 |
|------|------|
| 页面入场 | `fade-up`（cubic-bezier），Intersection Observer 触发 |
| 列表入场 | Stagger delay 50~75ms |
| Hover | `-translate-y-1` + shadow 增强 |
| 状态切换 | `fadeScaleIn` 0.2s |
| 加载骨架屏 | shimmer 扫光（`animate-pulse`） |
| 手风琴展开 | max-height 过渡 300ms |

### 响应式断点
| 设备 | 布局 |
|------|------|
| 移动端 | 单列 / 底部固定栏（44px 触摸目标） |
| 平板 | 双列 |
| 桌面 | 三列 / Sticky 侧边栏 |

### 无障碍
- 支持 `prefers-reduced-motion`
- 最小触摸目标 44px
- 语义 HTML（`aria-label`、`aria-current`）
- Toast 替代系统 `alert()` / `confirm()`
