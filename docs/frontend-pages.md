# GoMate 前端页面功能文档

> 最后更新：2026-03-26
> 架构：Astro 4 SSR 壳 + React Islands（client:load）

## 概览

前端共 21 个页面，按功能分为 7 个模块：

| 模块 | 页面数 | 是否需登录 |
|------|--------|-----------|
| 认证 | 4 | 否 |
| 地点 | 2 | 否 |
| 队伍 | 3 | 部分 |
| 用户 | 4 | 部分 |
| 首页 | 1 | 否 |
| 信息页 | 5 | 否 |
| 管理 | 1 | 是（Admin） |
| 用户功能 | 1 | 是 |

**关键交互：**

### 2. 地点列表页 `/locations`

**组件：** `components/features/locations-client.tsx`
**认证要求：** 否

**功能点：**
- Hero 搜索区（深色渐变背景）
  - 搜索框（玻璃效果 + 清空按钮）
  - 城市下拉筛选（单选，外部点击关闭）
  - 地点类型筛选（hiking 户外徒步 / explore 城市探索 / leisure 休闲探店 / travel 旅行）
  - 热门标签多选（点击切换激活态）
  - 已选条件 Badge（可逐个删除 / 全清）
- 地点卡片网格（3 列响应式，入场 stagger 动画）
  - 卡片信息：封面图、难度徽章、最佳季节、名称、地址、描述、标签
  - Hover：图片放大 + 卡片上升 + 阴影增强

- 空状态（浮动图标 + 情感化文案 + CTA 按钮）

**关键交互：**
- 搜索防抖 300ms

### 15. 重置密码页 `/reset-password`

**组件：** `components/features/reset-password-client.tsx`
**认证要求：** 否

**功能点：**
- 从 URL query 参数获取 `token`
- 新密码输入框（至少 6 位）
- 确认密码输入框
- 重置密码按钮
- 返回登录链接
- 表单验证：
  - 密码长度至少 6 位
  - 两次输入密码必须一致
  - token 有效性检查
- 状态展示：
  - token 加载中
  - token 无效（显示错误图标 + 重新发送链接按钮）
  - 重置成功（显示成功图标 + 跳转登录按钮）
  - 错误提示（红色警告框）

**关键交互：**
- 调用 Better Auth 客户端 `authClient.resetPassword()` 方法
- 成功后自动跳转到登录页

## 设计系统摘要

### 颜色体系
- **主色（品牌绿）**：Emerald `#249a87` / `#1a6459`
- **强调色（暖橙）**：Amber / Orange `#ff7a65` / `#fbbf24`
- **中性色**：Stone `#1e1812` / `#8f7f6e` / `#e8e7e4`

### 动效规范
| 类型 | 实现 |
|------|------|
| 页面入场 | `fade-up`（cubic-bezier），Intersection Observer 触发 |
| 列表入场 | Stagger delay 50~75ms |
| Hover | `-translate-y-1` + shadow 增强 |
| 状态切换 | `fadeScaleIn` 0.2s |
| 加载骨架屏 | shimmer 扫光（`animate-pulse`） |
| 手风琴展开 | max-height 过渡 300ms |

### 响应式断点
| 设备 | 布局 |
|------|------|
| 移动端 | 单列 / 底部固定栏（44px 触摸目标） |
| 平板 | 双列 |
| 桌面 | 三列 / Sticky 侧边栏 |

### 无障碍
- 支持 `prefers-reduced-motion`
- 最小触摸目标 44px
- 语义 HTML（`aria-label`、`aria-current`）
- Toast 替代系统 `alert()` / `confirm()`
