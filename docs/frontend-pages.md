# GoMate 前端页面功能文档

> 最后更新：2026-03-22
> 架构：Astro 4 SSR 壳 + React Islands（client:load）

## 概览

前端共 13 个页面，按功能分为 5 个模块：

| 模块 | 页面数 | 是否需登录 |
|------|--------|-----------|
| 认证 | 3 | 否 |
| 地点 | 2 | 否 |
| 队伍 | 3 | 部分 |
| 用户 | 4 | 部分 |
| 首页 | 1 | 否 |

---

## 页面详情

### 1. 首页 `/`

**组件：** `components/features/home-client.tsx`
**认证要求：** 否

**功能点：**
- Hero 区：大标题 + 渐变背景 + SVG 山脉装饰
- 搜索栏：关键词输入 + 清空按钮
- CTA 按钮组：「探索地点」「找队伍」
- 数字统计徽章：50+ 路线、200+ 玩家、1000+ 安全
- 精选地点卡片网格（3 列，含分页）
- 使用流程说明（3 步引导）
- 近期队伍卡片列表（双列，含倒计时提示）
- 浮动装饰卡片（大屏专属）

**关键交互：**
- 搜索跳转到地点列表页
- 页面滚动入场动画（Intersection Observer）
- 数字计数动画（CountUp）
- 视差滚动效果

### 2. 地点列表页 `/locations`

**组件：** `components/features/locations-client.tsx`
**认证要求：** 否

**功能点：**
- Hero 搜索区（深色渐变背景）
  - 搜索框（玻璃效果 + 清空按钮）
  - 城市下拉筛选（单选，外部点击关闭）
  - 热门标签多选（点击切换激活态）
  - 已选条件 Badge（可逐个删除 / 全清）
- 地点卡片网格（3 列响应式，入场 stagger 动画）
  - 卡片信息：封面图、难度徽章、最佳季节、名称、地址、描述、标签
  - Hover：图片放大 + 卡片上升 + 阴影增强
- 骨架屏（shimmer 扫光，加载时显示 6 张）
- 空状态（浮动图标 + 情感化文案 + CTA 按钮）
- 分页器（页码 + 省略号处理）

**关键交互：**
- 搜索防抖 300ms
- 城市 + 标签组合筛选
- URL 参数持久化（`q`、`tags`、`page`、`cityId`）
- 分页切换时 fade 过渡 + 卡片重新入场动画

### 3. 地点详情页 `/locations/[id]`

**组件：** `components/features/location-detail-client.tsx`

**功能点：**
- Hero 封面区（h-360 → h-560，双层渐变遮罩）
  - 分享按钮（Web Share API / 降级复制链接）
  - 收藏按钮（心形图标 + heartbeat 动效）
  - 面包屑导航
  - 难度徽章 + 最佳季节 + 标题
- 地点介绍卡（描述 + 标签列表）
- 路线信息网格（4 列：难度、时长、距离、爬升）
- 最佳季节标签（amber 背景）
- 地址信息卡
- 正在招募的队伍列表
  - 空状态：多层圆形装饰 + 「创建队伍」按钮

- 侧边栏 sticky 操作卡（「创建队伍」+ 「浏览队伍」）

**关键交互：**
- 分享（Web Share API 优先，不支持则复制链接）

### 5. 队伍详情页 `/teams/[id]`

**组件：** `components/features/team-detail-client.tsx`
**认证要求：** 是（未登录跳转 `/login`）

**功能点：**
- Hero 封面区（h-400 → h-520，双层渐变遮罩）
  - 分享按钮
  - 地点面包屑（可跳转地点详情）
  - 队伍标题
- 信息卡片（-mt-12 breakout）：状态徽章 + 4 列数据网格（日期、时间、人数、进度）
- 队伍描述卡
- 路线未定提示（条件渲染）
- 成员列表卡（超 6 人折叠，展开/收起带 ChevronDown 动效）
- 地点简介卡（缩略图 + 名称 + 跳转链接）
- 同地点其他队伍列表
- 桌面端侧边栏（sticky）
  - 队长信息卡
  - 加入操作卡（5 种状态）：
    - `canJoin`：进度条 + 留言 textarea + 申请按钮
    - `isPending`：待审批提示
    - `isMember`：已加入徽章 + 退出按钮
    - `isLeader`：已加入徽章 + 「管理队伍」链接
    - `isClosed`：关闭提示
  - 安全提示卡（4 条）
- 移动端底部固定栏（44px，safe-area-inset-bottom）
- 退出确认对话框（AlertDialog）
- Toast 消息提示（替代 alert()）

**关键交互：**
- 加入队伍（提交申请 + 留言）
- 退出队伍（二次确认）
- 成员列表折叠/展开
- 分享（Web Share API）
- Toast 成功/错误反馈

- 表单验证 + 提交后跳转队伍详情页

## 设计系统摘要

### 颜色体系
- **主色（品牌绿）**：Emerald `#249a87` / `#1a6459`
- **强调色（暖橙）**：Amber / Orange `#ff7a65` / `#fbbf24`
- **中性色**：Stone `#1e1812` / `#8f7f6e` / `#e8e7e4`

### 动效规范
| 类型 | 实现 |
|------|------|
| 页面入场 | `fade-up`（cubic-bezier），Intersection Observer 触发 |
| 列表入场 | Stagger delay 50~75ms |
| Hover | `-translate-y-1` + shadow 增强 |
| 状态切换 | `fadeScaleIn` 0.2s |
| 加载骨架屏 | shimmer 扫光（`animate-pulse`） |

### 响应式断点
| 设备 | 布局 |
|------|------|
| 移动端 | 单列 / 底部固定栏（44px 触摸目标） |
| 平板 | 双列 |
| 桌面 | 三列 / Sticky 侧边栏 |

### 无障碍
- 支持 `prefers-reduced-motion`
- 最小触摸目标 44px
- 语义 HTML（`aria-label`、`aria-current`）
- Toast 替代系统 `alert()` / `confirm()`
